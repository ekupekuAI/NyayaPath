# NyayaPath

NyayaPath is an independent citizen-first case-understanding product. It turns synthetic court case updates into a timeline, plain-language explanation, and next known step.

## Local Setup

1. Install dependencies:
   `npm install`
2. Configure server-side OpenAI, if live explanations are required:
   `OPENAI_API_KEY=...`
3. Run locally:
   `npm run dev`
4. Build for production:
   `npm run build`
   `npm start`

All bundled data is synthetic demo data. NyayaPath is not an official government service and does not provide legal advice.
